# Simply Chocolate

Освітній проект веб-сайту шоколадної компанії.

## Про проект

Це навчальний проект, створений для практики веб-розробки з HTML, CSS та
JavaScript.

## Структура проекту

- `index.html` - головна сторінка
- `css/` - папка з таблицями стилів
- `images/` - папка з зображеннями

## Сторінки

- Головна сторінка з героєм, переліком товарів, відгуками та іншими секціями

## Технології

- HTML5
- CSS3
